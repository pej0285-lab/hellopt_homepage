05사업장별로 필터링하여 별도의 파일로 저장하기

실습 파일 3.사업장분리.xlsx

교안 프롬프트 원문
엑셀의 '전체실적' 시트에서 지역본부별로 데이터를 분리
하여 각각 별도의 엑셀 파일로 저장하는 VBA 코드를 작성
해줘.

[조건]

• A1는 제목 영역, A3은 필드명, A4부터 데이터가 있어.
• A열의 지역본부를 기준으로 데이터를 분리해줘.
• 각 파일에 제목, 필드명 및 해당 지역본부의 데이터만
  포함해줘.
• 원본의 셀 서식과 열 너비를 유지해줘.
• 파일명은 '지역본부명.xlsx'로 지정해줘.
• 저장할 폴더는 사용자가 직접 선택하도록 해줘.
• 데이터 행이 늘어나거나 매크로를 다시 실행해도 정상
  작동하도록 해줘.

실습 파일 4.판매_분석.xlsx

원문 일부만 수록 · 13쪽 교안의 프롬프트는 ‘더 보기’로 접혀 있습니다. 아래는 보이는 부분이며, 생략된 내용은 추가하지 않았습니다.

교안 프롬프트 원문
아래 요구사항을 완벽하게 수행하는 엑셀 VBA 코드를 작
성해줘.

[데이터 환경]
- 원본 데이터 시트 이름: 'data'
- 데이터 범위: A열~H열 (A1: 주문일자, B1: 제품명, C1: 판
매채널, D1: 지역, E1: 수량, F1: 단가, G1: 판매금액, H1: 고
객ID)
- 1행은 헤더, 2행부터 데이터 시작

[요구사항]
1. 데이터 변환:
   - 'data' 시트의 전체 데이터를 엑셀 '표(ListObject)'로 변
환할 것.
   - 표의 마지막에 두 개의 필드(열)를 추가할 것.
     - '주문월': 주문일자에서 'm월' 형식 추출 (예: 2026-
01-01 -> 1월)
     - '사분기': 주문일자에서 사분기 추출 (예: 2026-01-01
-> 1사분기)

11사업장별 시트 분리

실습 파일 시트분리.xlsx

발표자 노트의 별도 프롬프트입니다. 본문의 지역본부별 파일 저장 실습과 조건이 다르며, 원문 그대로 수록했습니다.

교안 프롬프트 원문
전체실적 시트에 있는 데이터에서 사업장별로 시트 분리하는 VBA코드를 작성해줘 
[조건] 
- '전체실적' 시트에 데이터가 있어. 
- [A1:F3] 영역은 타이틀이야. 
- 데이터는 [A4] 셀부터 입력되어 있어. 
- 필터는 [A3] 셀부터 설정해야 해. 
- 데이터는 늘어날수 있어. 
- 고유한 사업장수를 카운트한 후에 사업장별로 데이터를 추출하고 시트 분리해줘. 
- 열 너비를 데이터에 맞게 자동 맞춤해줘. 
- 시트 이름은 각각의 고유한 사업장 이름으로 해줘. 
매크로를 다시 실행하면 에러 없이 다시 해당 작업을 실행할 수 있도록 해줘.
실행할 수 있는 방법을 한글로 설명해줘.

검색 결과가 없습니다. 검색어나 주제 필터를 바꿔보세요.
