# HelloPT Homepage

Korean promotional homepage for Park Eunjin, Microsoft Certified Trainer and AI productivity instructor.

## Demo

Netlify: https://hellopt-homepage.netlify.app/

GitHub Pages: https://pej0285-lab.github.io/hellopt_homepage/

## Features

- Instructor profile and lecture history
- Training program overview
- Hands-on lab resource cards
- Lecture inquiry form using mail client composition
- GitHub Pages deployment with GitHub Actions

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
